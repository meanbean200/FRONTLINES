# Clean battlefield HUD

Implemented the user's three browser annotations: remove the persistent force roster, remove the permanent selected-squad card, and make the objectives cleaner and higher.

## Changes

- Roster and selection details are closed by default at every screen size. The small existing **Force** and **Squad** toggles retain access to selection, engineering, building floors and other contextual actions. Selecting troops does not automatically reopen either card.
- On the reported 1654×910 desktop size, objectives start at y=24 instead of y=91. The strip is 444×59 CSS pixels, with clickable ownership markers and a short win-condition line. The redundant mode heading and aggregate personnel/casualty text are removed from normal view. Short-operation countdowns remain visible.
- Removed the command dock's extra title row and the always-on generic movement hint. Active drawing/placement instructions still appear.
- The collapsed Defend Area and Support & rescue controls now align with a gap on desktop. The first screenshot pass caught their overlap after the objective strip moved; final checks verify separation.
- Narrow/short windows retain scrolling opt-in drawers and accessible controls.

Implementation is limited to `src/responsive.css`. No JavaScript, simulation rules, game state, save schema, inventories or local-storage values were changed. CSS hot updates do not require reloading the user's live 4173 game. The local server returned the updated stylesheet successfully. Automated browser checks used only the separate existing Edge QA session at 4175; the user's 4173 browser was not refreshed.
